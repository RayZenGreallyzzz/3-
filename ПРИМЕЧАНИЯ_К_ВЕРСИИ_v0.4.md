Полный проект редактора для Android/ПК, соответствующий **Rig & Weapon Studio v0.4**, протестированной пользователем и успешно собранной на GitHub Actions как **APK №18**.

- Репозиторий: https://github.com/RayZenGreallyzzz/3-

- Успешная сборка APK №18: https://github.com/RayZenGreallyzzz/3-/actions/runs/38492180407

- Архивная ветка отличается от проверенного commit программы **только этим файлом примечаний**, остальные файлы идентичны.

## Возможности программы

1. Загрузка GLB, GLTF, FBX, OBJ, DAE, STL, PLY, включая анимации поддерживаемых форматов.
2. Анимационный плеер: выбор клипа, старт, пауза, остановка, скорость, перемотка.
3. Отображение скелета, поиск костей и выбор места крепления оружия.
4. Привязка/отвязка оружия от кости; настройка положения, поворота и масштаба.
5. Скрытие цветных осей манипулятора и разворачивание 3D-сцены.
6. Независимые кнопки удаления персонажа и оружия, сброс трансформации.
7. Панель **«Поза рук»**: левая и правая рука, ключица, плечо, предплечье, кисть; поправки поворота X/Y/Z с ограничителями, отдельный сброс сустава и руки. Автоопределение Mixamo-костей и ручной выбор нестандартной кости.
8. Наложение поворотов рук поверх движущейся анимации без накопления ошибки от кадра к кадру.
9. Сохранение GLB с оружием и совместимыми анимациями; перенос поправок в совместимые quaternion-ключи.
10. Нативное окно выбора папки/имени файла в Android; сохранение GLB и JSON через системный файловый менеджер.
11. Повторная загрузка сохранённого GLB с возможностью редактировать встроенное оружие.
12. Основная работа приложения без интернета/сервера. GitHub нужен только для исходников, обновлений и облачной сборки APK.

## Как собрать снова

Установить Node.js 22+, а для Android локально также Java 21 и Android SDK.

```bash
npm install
npm run test:pose
npm run build
```

Для просмотра на компьютере: `npm run dev`.

Для Android можно просто использовать уже настроенный GitHub Actions: **Actions → Build Android APK → завершённая сборка → Artifacts → Rig-Weapon-Studio-APK**. Внутри скачанного артефакта находится `app-debug.apk`.

**Важно:** папки `android/`, `node_modules/` и `dist/` намеренно не лежат в исходниках. Проект Android генерируется в сборке через Capacitor, а файл `NativeFileSaverPlugin.java` встраивается отдельным шагом. Это полноценные исходники проекта, а не отсутствующие компоненты.

## Что проверять после будущих изменений

- **Импорт → привязка оружия к кисти → перемещение/вращение/масштаб → экспорт GLB → повторный импорт → повторное редактирование оружия → сбросы по отдельности.**
- В режиме «Поза рук» поправки должны держаться во время `Strafe_Right` или другой анимации и исчезать после сброса соответствующего сустава.
- После экспорта GLB повторно открыть его и проверить не только внешний вид, но и воспроизведение анимации, положение оружия, работу кнопок и выбор кости.
- При доработках сохранения Android нельзя заменять плагин `NativeFileSaverPlugin` обычной HTML-ссылкой для скачивания: это уже вызывало проблемы в Android WebView.
- Обязательно сохранять лёгкость работы для слабого планшета. Проверять память на крупных моделях.
- После каждой модификации запускать тесты и GitHub Actions, затем проверять APK на реальном планшете.
- Новые экспериментальные изменения делать в отдельной ветке, **не перезаписывая эту резервную копию**.

## Текущие ограничения

- Ручная настройка суставов **не является IK**. Кисть не тянет плечо и локоть автоматически; поворачиваются существующие кости.
- Качество сгибов зависит от исходных весов скининга. Исправление весов вершин не реализовано.
- Не все экзотические FBX/DAE-анимации одинаково поддерживаются GLB-экспортом. Некоторые несовместимые анимации могут не попасть в сохранённый GLB; программа об этом предупреждает.
- Поправки к суставам запекаются в quaternion-треки. Другие варианты треков могут требовать дополнительной реализации.
- Преобразование в FBX 2013 и ниже отсутствует; выходной формат основного экспорта — GLB.
- Большие модели с тяжёлыми текстурами могут замедлять или перегружать устройство.

## Идеи будущих обновлений

- Сохранение отдельных пресетов хватов и поз рук под каждый тип оружия.
- Необязательная IK-подстройка второй кисти к рукояти двуручного оружия.
- Отдельная Animation Studio для редактирования ключевых кадров.
- Отдельная офлайн MoCap Studio: захват торса, плеч, рук и головы с видео/камеры; таз и ноги остаются неподвижны.
- Оптимизация моделей и текстур для слабых Android-устройств.
